🟩 PROBLEM DESCRIPTION

You are asked to create a small program that collects personal information, performs calculations, checks conditions, and displays various outputs.

ex:

Create the following variables:

Your name (string)
Your age (number)
Are you a student? (boolean)
A variable named temperature (number — any value you choose)

String concatenation
Template literals
Example:
(My name is ___ and I am ___ years old.)   <-- concatenation
(My name is name and I am age years old.)   <-- template literal

4️⃣ Perform Basic Math Operations

Create two number variables and print:

Addition
Subtraction
Multiplication
Division
Modulo

5️⃣ Use an if/else Statement

Using the temperature variable:
Print "It’s cold!" if temperature < 20
Print "The weather is nice." if temperature is between 20 and 30
Print "It’s very hot!" if temperature > 30
