PHP Coding Checklist (Basic → Hard)

BASIC

Print “Hello World”
Create variables ($name, $age, $price)
Use string concatenation
Use basic math operators (+, -, *, /, %)
Write if, else, elseif
Write a simple for loop
Write a while loop
Create your first function
Return a value from a function
Use comments (//, /* */)

BEGINNER

Use switch for options
Create indexed arrays and access elements
Create associative arrays and access values
Loop arrays using foreach
Use break and continue
Use default function parameters
Create an anonymous function (closure)
Use isset, empty, is_numeric, etc.
Read form input using $_GET
Read form input using $_POST

INTERMEDIATE

Sanitize input (trim, htmlspecialchars)
Validate form fields (required, length, email format)
Read files using file_get_contents()
Write files using file_put_contents()
Convert array to JSON (json_encode)
Convert JSON to array (json_decode)
Build a PHP script that outputs JSON
Create custom error message handling
Use sessions (set, read, destroy)
Use cookies (set, read, delete)

INTERMEDIATE+ (Database & Security Basics)

Connect to MySQL using mysqli
Connect to MySQL using PDO
SELECT data and display it
INSERT data using prepared statements
UPDATE data using prepared statements
DELETE data using prepared statements
Prevent SQL Injection using binding
Escape HTML output with htmlspecialchars
Hash passwords using password_hash
Verify passwords using password_verify

ADVANCED

Build a PHP REST API (GET/POST/PUT/DELETE)
Return JSON for JavaScript fetch requests
Upload a file using $_FILES
Validate file type (image/pdf)
Validate file size
Store uploaded file in a custom directory
Create pagination using SQL LIMIT
Generate CSRF token
Validate CSRF token on form submit

ADVANCED+

Create a reusable database class (OOP)
Build your own router (URL → function)
Create a simple MVC structure
Use PHP exceptions (try/catch)
Handle database transactions (begin, commit, rollback)
Implement role-based access (admin/user)
Protect pages using login sessions

HARD / EXPERT

Build JWT-based login system
Build a token-based API for mobile apps
Create a custom error logger (log to file)
Build SQL caching layer (store results in file/memory)
Build a secure file download system
Write your own validation library (email, regex, numbers)
Implement advanced security headers
Optimize SQL queries (indexes, joins)
Build a full small system using PHP + MySQL + fetch API
